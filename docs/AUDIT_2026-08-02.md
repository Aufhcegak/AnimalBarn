## 一、已确认并修复（本次会话）

### ✅ 1. 侧墙门贴地图边缘 → 踩空（高危，已修）
- **症状**：玩家从西/东侧门走进去，再往外一步直接掉出地图（踩空）。
- **根因**：旧门洞在 x=0 / x=Width-1（贴地图边缘），门洞外侧越界。
  `isTilePassable(null)` 返回 true → 走出地图进虚空。
- **修复**：侧门改成**凹进门龛**（门洞在 x=1 / x=Width-2），门后 x=0 / x=Width-1 是实心墙，
  玩家朝门走一格就触发 warp，物理上不可能走出地图。
- 涉及：`LobbyMapBuilder.DoorPositions`、`BarnMapRecipe.SealSides`（整列封死）、`LobbyDoors.FacingIntoRoom`（按 x=1/Width-2 判朝向）。

### ✅ 2. 底行出口 3 格大缺口 → 只有中间格有 warp，两侧踩空（高危，已修）
- **症状**：大堂南出口和房间南出口都是 3 格宽缺口（x=5,6,7），但只有中间 1 格有 warp，
  玩家走到两侧缺口格往下就走不出、还容易踩空。
- **修复**：出口**收窄成 1 格**（原版门宽），两侧铺门框柱 `PlaceWallPost` 收口。
- 涉及：`LobbyMapBuilder` / `RoomMapBuilder` 的 `southDoors = { DoorX }`。

### ✅ 3. 兔房门被挂钉堵死（高危，已修）
- **症状**：北墙兔门（x=9）进不去——门洞位置被 `AddWallDecor` 的挂钉（width-4=9）占了。
- **修复**：北门改 x=3,6,10（避开挂钉 x=2 与 x=9），窗挪到 x=1,2,11。

### ✅ 4. 羊购买/升级 → RoomDefinitions.Get(Sheep) 抛异常（高危，已修）
- **根因**：羊与山羊共用羊场（9 动物 8 房），`RoomDefinitions` 没有 Sheep 房，
  `Get(Sheep)` 的 `First()` 抛异常被 SMAPI 静默吞 → 按钮无反应。
- **修复**：新增 `RoomDefinitions.RoomFor()`（Sheep→Goat），`BuyAnimal`/`UpgradeRoom` 全用 RoomFor。

### ✅ 5. 升级羊场 → 建幽灵 "Sheep" 房间键，容量永远不升（中危，已修）
- **根因**：`UpgradeRoom` 用 `state.GetRoom(room)`（动物类型）而非 RoomFor，
  升级的是不存在的 Sheep 房间，羊场容量不变。
- **修复**：统一 `houseRoom = RoomFor(room)`。

### ✅ 6. 升级后 UI 仍显示旧等级（中危，已修）
- **根因**：`RefreshSnapshotCounts` 只刷数量/容量，不刷 UpgradeLevel/OverallLevel；
  快照 record 又只读。
- **修复**：快照加可变属性，`RefreshSnapshotCounts` 完整刷新（等级/解锁/容量/整体）。

### ✅ 7. 房间里看不见动物（高危，已修）
- **根因**：买动物只写台账，从不生成实体 FarmAnimal。
- **修复**：新建 `RoomAnimalRenderer`，买入/进门时把台账前 30 只实例化成真动物
  （构造 `FarmAnimal(string, long, long)` 经反射验证；home 是 Building）。
- ⚠️ **待实机验证**：实体动物只在真游戏渲染（xnbdump 画不出），需进游戏确认走动/喂食。

### ✅ 8. 中枢干草堆 → 电脑台（中危，已修）
- 撤掉干草 tile，改 `ComputerConsole : Object`（基底 Farm Computer (BC)239）自绘贴图；
  加了无参构造（防读档 NetRef 崩溃）+ EnsurePlaced 幂等（读档回退成原版电脑时换回）。

### ✅ 9. 建筑外观透明/黑边（已修，上一轮）
- 112x128 裁到 **112x112**（SrcRect 对应），四边无透明（本次视觉复核通过）。

## 三、未修复 / 待 DeepSeek 或实机确认

### ⚠️ A. 联机客机 desync（中危，代码已确认未接线）
`EdgePolish.CanModifyState()`（主机权威）**没有**接进 HubMenu 的购买/升级/存取动作。
客机改本地 modData 会被主机同步覆盖 → 花钱但动物消失。
**修法**：HubMenu 各动作开头加 `if (!EdgePolish.CanModifyState()) { Notice("联机下只有主机能操作"); return; }`。

### ⚠️ B. 房间实体动物 <-> 台账同步（需实机验证）
`RoomAnimalRenderer` 生成实体后，每日 `SettleRoom` 的 `SyncLedgerFromEntities` 会双向同步。
**风险点**：实体可能双结算（原生 dayUpdate + 台账 SettleDay）→ 产物/好感重复。
已尽量分离（实体走原生、台账走 SettleDay），但**必须实机看一天产几次**。

### ⚠️ C. 干草双扣（需实机验证）
实体动物干草走原生 AutoFeed（从干草槽 tile），台账走全局 HayStock，两套独立。
**风险**：实体与台账对同一动物各扣一份 → 干草消耗偏高。需实机核对每日消耗。

### ⚠️ D. 读档后电脑台（需实机验证）
自定义 Object 子类在 `objects` 里，读档可能被序列化器回退成原版 Farm Computer。
已加 EnsurePlaced 兜底（检测到 (BC)239 就换回），**需实机读档确认**。

### ⚠️ E. 升级档位索引（代码确认正确，实机复核一次）
`Overall[Clamp(level,0,4)]` 语义 = 升到 level+1 的档，level 1→2 用 Overall[1]（35000g）。正确。

### ⚠️ F. 干草购买"挤一起"（上一轮已把按钮间距拉开到 210px，实机确认）
4 个档位按钮：`ContentLeft+40 + i*210`，宽 190。若仍挤说明字太长，可再拉开。

### ⚠️ G. 拆除保护（代码已写 DemolitionGuard 双补丁，实机验证）
非空养殖场禁止拆除（菜单内红字 + destroyStructure 硬兜底）。

### ⚠️ H. 产物拦截（代码已写，实机验证）
`Utility.spawnObjectAround` prefix 拦产物进仓库。需实机确认蛋/奶不落地、进仓库可取。
